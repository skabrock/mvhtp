# Onboarding form

## Run

```bash
npm install
npm run dev
```

Or with bun: `bun install` then `bun dev`.

## Test

```bash
npm test
```

Or `bun run test`.

## Stack

- **Next.js 16**
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **React Hook Form** + **Zod**
- **TanStack Query**
- **Sonner**
- **Lucide React**
- **Jest** + **React Testing Library**
